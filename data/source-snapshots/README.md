# Pinned source snapshot

`Jiten-Frequency-2026-11-16.zip` is an unmodified snapshot of Jiten’s global Yomitan frequency export, downloaded from https://api.jiten.moe/api/frequency-list/download?downloadType=yomitan on 2026-11-16.

Data: Jiten / Jitensoft and contributors. CC BY-SA 4.0. The official redistribution statement is https://jiten.moe/guides/yomitan-frequency-dictionaries and the licence is https://creativecommons.org/licenses/by-sa/4.0/. The original index and source identity are preserved inside the ZIP.

This is a build input, not an additional installation requirement. End users import only their English or German Kotoba Atlas edition. The snapshot fixes a daily-changing upstream resource for reproducible source retrieval; its hash is pinned in `data/sources.json`.
