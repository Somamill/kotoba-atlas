# Local dictionary folder audit

The owner supplied an iCloud dictionary folder for read-only inspection. No source files were changed.

| Found | Decision |
|---|---|
| WaDoku Yomitan | Use the newer official July 2026 export in both builds; keep source attribution and licence. |
| Older JMdict German / JMnedict | Use the newer November 2026 releases already downloaded. |
| KANJIDIC English | Add the current November 2026 release; character meanings and on/kun readings become labeled lookup text. |
| Innocent Corpus | Additional older frequency data; omitted to avoid stacking redundant ranks without verified redistribution terms. |
| KireiCake | Not selected: upstream is inactive and published quality concerns describe unreliable non-JMdict material. Modern JMdict/Jitendex and Wiktionary are the English sources. |
| Super Daijirin | Optional personal build only, from the user's existing copy. Not uploaded. |
| Meikyo StarDict | Not included: commercial data and a separate resource-dependent format. No public redistribution rights assumed. |
| Other StarDict / Kobo dictionaries | Not selected: different formats, older duplicates, or unrelated language pairs. |
| Chinese dictionaries | Not selected for this Japanese-focused collection. |

Personal builds may include commercial/local material only for the owner's own use. The public release never reads or uploads the folder. Source coverage is not equivalent to parser accuracy or a complete account of slang and nuance.
