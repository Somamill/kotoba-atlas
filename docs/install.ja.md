# Kotoba Atlas のインストール

[ダウンロード一覧](../README.md#download)から、利用するアプリに合った形式を選んでください。

## Migaku / Yomitan

1. 英語版またはドイツ語版の ZIP を一つダウンロードします。ドイツ語版には、ドイツ語の情報がない項目用の英語も含まれます。
2. **ZIP を解凍しないでください。** ブラウザが自動で解凍する場合は、その設定を無効にして再ダウンロードします。
3. 拡張機能の辞書設定で「ファイルからインストール」または「インポート」を選び、ZIP を指定します。完了するまで設定画面を閉じないでください。
4. インストール済みの一覧に辞書が表示されることを確認し、物ノ怪とノリのいいを検索します。進捗が動くだけでは、完了したとは限りません。

ベータ版の ZIP 全体は、固定バージョンの Yomitan パーサーと公開されている旧 Migaku インポーターで検証しています。現在の拡張機能での実際のインストール検証は未完了です。アクセント・頻度・漢字情報の表示は、利用するアプリにも依存します。

## ネイティブアプリ

対応アプリでは共通コアと同じ版の言語パックを使用します。ネイティブ用の `.sqlite.gz` は、ブラウザ拡張機能にはインポートできません。対応アプリは有効化前にハッシュと互換性を検証し、履歴や学習記録を辞書とは別に保存します。

十の定義言語に対応しますが、収録範囲は言語・出典によって異なります。中国語・アラビア語・ポルトガル語は、現時点では説明的な定義ではなく対応語を収録しています。[収録範囲と出典](releases/atlas-v1.1.0-beta.2.md)。
