# Kotoba Atlas 1.0.4 beta 2

Rebuilt, reproducible native app packages and working download catalogue for dict. The English and German complete dictionary ZIPs retain every non-index member of 1.0.3 unchanged. This prerelease does not change the stable latest release.

Native packages retain all source fields, metadata, kanji, tags and licence notices; every row was compared against its matching ZIP. Full native English ships inside dict. for first-launch offline use; German downloads once. One complete import ZIP per definition language remains the recommended Migaku/Yomitan download. Native SQLite packages are for the app; Lookup Lab is an optional source toolkit, not an executable dictionary extension.

Validation: 34 helper tests pass with optional Sudachi dependencies installed; 10 real-archive phrase regressions pass per language; both ZIPs pass pinned Yomitan schema/source licence/transfer budget checks. Native parity reports and asset hashes are alongside this note. Native app testing is separate and reported in the dict. repository. Frozen beta-1 held-out retrieval reports do not establish sense accuracy, universal coverage or native app accuracy.
